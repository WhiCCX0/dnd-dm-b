# D&D 5e Session 0 极速启动与开局接口规范 (Session 0 Starter Interface)

> **核心定位**：本文件是《D&D 5e 中文全规则跑团 (2024修订版)》的**官方 Session 0 唯一标准开局接口**。当玩家发出开局消息（如“我想跑团”、“开始DND”、“开一局DND”）时，DM 必须严格调用本规范，直接输出极速启动引导卡。

---

## 一、 Session 0 开局总纲与执行铁律

1. **直接切入，绝不啰嗦**：读取本接口后，不解释庞杂的规则背景、不进行多轮问卷轰炸，直接输出下方的启动引导卡。
2. **三步极速启动 + 可选偏好微调架构**：
   - **第一步 · 模式与人数**：明确跑团风格（冒险沉浸 / 🌱萌新保姆教学 / 规则调试）。单人跑团主动配置忠诚随从——矮人斥候**【布兰·铁须】**（1级随从，HP 12，AC 14，见 `resources/premade-characters/sidekick-bran.md`）；
   - **第二步 · 角色选择**：提供 6 套严格按 2024 规则校验的预制角色卡（所有数值与 `resources/premade-characters/presets.json` 同源绑定），支持 `--preset <id>` 一键初始化；
   - **第三步 · 剧本选择（诚实分级）**：明确区分 **【A类：DMG 2024 官方完整短冒险（库内含完整正文与主持包）】**、**【B类：原创完整开箱模组】** 与 **【C类：5e 经典战役风格改编（诚实说明库内仅含怪物/宝物附录，剧情由 DM 改编主持）】**；
   - **可选附加项 · 安全边界与风格偏好**：涵盖内容边界（红线/帷幕）、叙事语气与战斗/探索/社交比例，**默认一键跳过**，绝不增加额外问卷轮数。
3. **极速开跑指令 (Pick & Play)**：
   - 玩家可直接回复编号组合（例如：“**① ① ①**” 即代表：沉浸模式 + 战士瓦伦 + 《秽染溪泉》）；
   - 亦可整段回复“**随机**”，由 DM 调用真骰脚本自动代抽全套开局配置并直接推进至第一场景。
4. **第一场景强制硬下锚**：
   - 收到玩家选择后，DM 立即调用 `state.js init <战役名> --preset <角色ID[,bran]>` 完成底层状态初始化，第一句直接切入视听现场；
   - 场景中必须包含至少 3 个可交互的环境实体（如倾覆的货车、燃烧的火把、地上的血迹）。

## 三、 第一场景下锚规范 (First Scene Anchoring)

收到玩家指令后，DM 必须立即调用状态脚本初始化队伍并严格按以下标准输出正文：

1. **真实状态初始化**：
   执行 `node <SKILL_DIR>/scripts/state.js init <战役名> --preset <角色ID[,bran]>` 建立持久化 JSON 存档。
2. **真实视听冷钢切入**：
   第一句必须直接描写现场感官（腐叶下的黑水气味、冻雨落在铁盔上的脆响、翻倒马车的裂木），严禁出现“欢迎来到 DND 世界”、“你的旅程开始了”等出戏套话。
3. **三项环境交互实体**：
   场景内明确放置至少 3 个具有战术或探索价值的物理实体。
4. **行动引导与初始 HUD 状态栏**：
   萌新模式下文末必须提供【四选一行动脚手架】（沉浸模式下仅在玩家卡壳或询问时提供），并在底部挂载与 `state.js` 完全一致的初始 HUD 状态栏。
