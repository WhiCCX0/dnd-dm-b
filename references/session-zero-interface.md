# D&D 5e Session 0 极速启动与开局接口规范 (Session 0 Starter Interface)

> **核心定位**：本文件是《D&D 5e 中文全规则跑团 (2024修订版)》的**官方 Session 0 唯一标准开局接口**。当玩家发出开局消息（如“我想跑团”、“开始DND”、“开一局DND”）时，DM 必须严格调用本规范，直接输出三步极速启动引导卡。

---

## 一、 Session 0 开局总纲与执行铁律

1. **直接切入，绝不啰嗦**：读取本接口后，不解释庞杂的规则背景、不进行多轮问卷轰炸，直接输出标准的三步启动引导卡。
2. **三步极速启动架构**：
   - **第一步 · 模式与人数**：明确跑团风格（冒险沉浸 / 🌱萌新保姆教学 / 规则调试）。单人跑团主动赠送忠诚随从（矮人斥候布兰或见习牧师米拉）；
   - **第二步 · 角色选择**：提供 6 套精制 2024 预制角色卡（附带招牌武器精通与核心法术）一键认领，或提供自建角色卡链接；
   - **第三步 · 剧本推荐**：提供 1 部自创新手开箱模组与 3 部官方经典模组。
3. **极速开跑指令 (Pick & Play)**：
   - 玩家可直接回复编号组合（例如：“**① ① ①**” 即代表：沉浸模式 + 战士瓦伦 + 《低语地窖》）；
   - 亦可整段回复“**随机**”，由 DM 自动掷骰代抽全套开局配置并直接推进至第一场景。
4. **第一场景强制硬下锚**：
   - 收到玩家选择后，DM 立即完成底层状态初始化（`scripts/state.js init ...`），第一句直接切入视听现场；
   - 场景中必须包含至少 3 个可交互的环境实体（如倾覆的货车、燃烧的火把、地上的血迹）；
   - 行动交还节点必须输出【场景化四选一行动脚手架】与【极简 HUD 状态栏】。

## 三、 第一场景下锚规范 (First Scene Anchoring)

收到玩家指令后，DM 必须立即在终端执行状态初始化并严格按以下标准输出正文：

1. **真实视听冷钢切入**：
   第一句必须直接描写现场感官（马车翻倒的裂木、冻雨落在铁盔上的脆响、扑鼻的硫磺味），严禁出现“欢迎来到博德之门”、“你的旅程开始了”等出戏套话。
2. **三项环境交互实体**：
   场景内明确放置至少 3 个具有战术价值的物理实体（如：翻倒的马车掩体、两只咽喉中箭的死马、两侧茂密易燃的荆棘丛）。
3. **首个四选一行动脚手架**：
   文末必须提供 3 个带检定/技能提示的战术行动 + 1 个自由行动入口。
4. **极简 HUD 状态栏**：
   回复最底端必须挂载标准的单行 HUD（HP、AC、药水、状态）。
