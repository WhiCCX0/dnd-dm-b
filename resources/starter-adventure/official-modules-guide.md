# D&D 官方 38 部经典模组 DM 主持与快速选本指南

B 版技能内部整合了官方 38 部已翻译模组的全部核心资产（首领数据卡、专属魔法物品、特殊机制与剧情手记）。DM 可根据玩家喜好与等级快速推荐并主持以下经典官方战役：

---

## 一、新手推荐模组 (1–5 级)

### 1. 《凡达林的失落矿坑》(Lost Mine of Phandelver) ⭐⭐⭐⭐⭐
- **适用等级：** 1–5 级 | **风格：** 经典奇幻、探索、清剿地精、拯救小镇
- **背景：** 矮人格兰德·摇岩雇佣冒险者护送马车前往凡达林镇，路上却发现了被伏击的死马与地精脚印……
- **核心敌人与首领：** 峭壁地精、红标帮暴徒、巨魔、绿龙幼龙、首领“黑蜘蛛”那兹纳尔
- **DM 调取指令：**
  ```bash
  node scripts/lookup.js module "矿坑"
  node scripts/lookup.js monster "黑蜘蛛"
  node scripts/lookup.js monster "地精武者"
  ```

### 2. 《冰塔峰巨龙》(Dragon of Icespire Peak) ⭐⭐⭐⭐⭐
- **适用等级：** 1–6 级 | **风格：** 任务板接单制、沙盒探索、白龙狩猎
- **背景：** 年轻的白龙“冰尖”进驻冰塔峰，逼得周围的兽人与怪物四处逃窜，凡达林镇长在镇长宅邸门前贴出了悬赏公告……
- **亮点：** 原生自带单人随从系统（Sidekick），极其适合 1 名玩家游玩！
- **DM 调取指令：**
  ```bash
  node scripts/lookup.js module "冰塔峰"
  node scripts/lookup.js monster "青年白龙"
  ```

## 二、中高阶与史诗战役模组 (1–10+ 级)

### 3. 《施特拉德的诅咒》(Curse of Strahd) ⭐⭐⭐⭐⭐
- **适用等级：** 1–10 级 | **风格：** 哥特式恐怖、吸血鬼始祖、密闭浓雾鸦阁魔域
- **背景：** 诡异的黑雾将冒险者吞没，醒来时已置身于阴郁的巴罗维亚。远方高耸的鸦阁堡尖塔上，吸血鬼领主施特拉德·冯·扎罗维奇正在凝视着你们……
- **DM 调取指令：**
  ```bash
  node scripts/lookup.js module "施特拉德"
  node scripts/lookup.js monster "施特拉德"
  node scripts/lookup.js item "日圣符"
  ```

### 4. 《深水城：龙金劫》(Waterdeep: Dragon Heist) ⭐⭐⭐⭐
- **适用等级：** 1–5 级 | **风格：** 城市调查、多帮派博弈、寻找五十万金龙宝藏
- **背景：** 费伦最璀璨的明珠——深水城暗流涌动。贪腐前领主私藏的五十万金币藏宝库线索现世，各大阵营倾巢出动！
- **DM 调取指令：**
  ```bash
  node scripts/lookup.js module "龙金劫"
  ```

### 5. 《博德之门：坠入阿弗纳斯》(Descent into Avernus) ⭐⭐⭐⭐
- **适用等级：** 1–13 级 | **风格：** 地狱圣战、疯狂麦克斯废土战车、救赎堕落天使
- **背景：** 艾尔托瑞尔全城被拖入九层地狱的第一层——阿弗纳斯。唯有无畏的英雄敢踏入血战战场！
- **DM 调取指令：**
  ```bash
  node scripts/lookup.js module "阿弗纳斯"
  ```

### 6. 《烛堡谜案》(Candlekeep Mysteries) ⭐⭐⭐⭐
- **适用等级：** 1–16 级 | **风格：** 17 个独立的魔法藏书悬疑短篇
- **背景：** 坐落在剑湾悬崖上的伟大图书馆“烛堡”，每一本带有秘密的古籍都是一扇通往异界的门扉。
- **DM 调取指令：**
  ```bash
  node scripts/lookup.js module "烛堡"
  ```
