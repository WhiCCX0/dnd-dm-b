# 剑火纪元（Jianhuo Era）常驻微型设定胶囊 (`capsule.md`)

> 旧帝国的剑已折断，新秩序的火尚未点燃——这是一个所有道路都还没被封死的时代。
> **谱系定位（风格总锚，母本第 14 行定案）**：本世界属于**西方奇幻传统**（《龙与地下城》《指环王》《魔兽世界》一脉）——位面宇宙与多种族共存是它的骨架，魔法作为被社会管理的力量是它的日常，旧秩序崩解的余烬史诗感是它的基调：精灵的长寿与疏离、矮人的石厅与锻炉、兽人的部族与战歌、侏儒的魔导工学、魔族的契约与阶序、王座厅、纹章、挂毯、石砌城堡、公会、法师塔、神殿、集市、酒馆、佣兵——而非任何东方式宫廷、庙堂或武侠修真意象。这个世界有自己的具体质感（浮空城的粮食软肋、侏儒的魔导工学、五道法统的社会位置），一切描写从设定推导，严禁串味。

## 一、开放世界框架与裁决底线
1. **裁决优先级**：`D&D 2024 数值与行动/施法规则 > 本存档既定事实（canon） > 剑火纪元设定切片（lore/*.md） > 即兴叙事`。
2. **统一四段开放框架**：各地区、势力、教会与结社均按 **骨架（定论） / 素材（传说/可选） / 矛盾与钩子 / 留白问题** 组织。除骨架与 2024 规则硬边界外，主持 DM 可自由改写与扩充，一经桌边定案即记入存档 `canon`。
3. **地图边缘留白**：已知大陆之外的外洋与西漠尽头、**万门之城**上千座古石门之后、以及各位面与地底最深处，只保留方向提示，绝不写死边界。
4. **数值准绳与双层保密**：法术位、施法成分、护甲熟练、武器精通与复活法术完全遵循 D&D 2024；不设法术枯竭扣值、铁护手禁施法、破戒自动暴毙或禁复活法则杀。玩家认知按地点五层门槛（`凡俗层 / 文明层 / 超凡层 / 异界层 / 诸界层`）过滤；`secret/gm-dossier.md` 严禁直出。

## 二、世界七律、历法与货币
- **世界七律**：**恒动**（世界在玩家离场时持续推进）、**稀缺**（资源有成本，重复刷取收益递减）、**代价**（超凡、神恩与政治皆明码标价记入 `ledger`）、**凡识**（开局认知受身份限定）、**因果**（改革与杀伐必招反扑余波）、**死亡**（NPC 死亡真实；2024 合法复活法术机制有效，但伴随宗教与政治后果）、**惯性**（旧战火与宿怨持续塑造当下）。
- **标准历法**：一年十二个月（`360 天`，每月三旬 `30 天`），以纪元代年（默认**剑火纪**）；每日分 `深夜 / 黎明（04:00 结算点）/ 上午 / 下午 / 黄昏 / 夜`。七纪元：`神启纪 → 古族纪 → 辉法纪 → 列王纪 → 崩渊纪 → 帝国纪 → 剑火纪`。
- **货币与魔晶**：物价对齐 PHB 2024，十进制 `1 gp = 10 sp = 100 cp`（D 模式底层统一以整数铜币 `inventory.copper` 记账，展示折算 `gp/sp/cp`）。旧帝国龙纹金币、咬铅劣银、剪边碎银、半子与铁销作叙事成色风味；**魔晶**分下/中/上/极品四等，属炼金附魔与魔导燃料，非施法强制税。

## 三、七大国度、新增候选疆域与四大走廊
- **七大地缘国度（骨架）**：
  1. **圣座同盟 · 灰岩十一邦**：中南部灰岩裂谷群，圣骸大教堂、三大圣骑士团与十一世袭大公双轨共治（并入卡斯蒂亚圣战庭可选素材）。
  2. **高塔议会 · 埃瑟加德**：西侧断裂带上空浮空塔群（**真理之柱、星轨之枢、苍穹之冠**），天港输粮，悬崖底为剧毒**落灰区**；苍穹之冠对外流传每年缓慢下沉两寸。
  3. **铁锚自由同盟与万门海湾**：东海岸围绕**万门之城**千座古石门修筑的商贸寡头港湾，海运公会、侏儒精算托拉斯与铁钩海盗同盟共推执政（并入瓦尔德联省与自由港船团素材）。
  4. **北境霜荒 · 氏族要塞盟军**：极北冻原**拒冬墙**十二地堡，兽人、矮人与人类黑鸦先锋军联防（并入诺德封建边堡素材）；极北冬线**往年每年仅向南推进一寸，今年骤然加速至半里**。
  5. **沉日绿沼与旧行省自治公社**：西南海水倒灌泽国，**芦苇议会**高脚屋自治，打捞**沉没帝都**遗物（并入腐殖泥沼素材）。
  6. **熔火裂隙与深渊黑铁王宫**：中央山脉地底三千尺矮人王城，铁砧国王与长老院共治，第七坑道直面深层异形（并入铁炉氏族素材）。
  7. **哀嚎铁壁 · 渊口督战军阀兵团**：横跨**哀嚎裂谷 / 深渊第九裂口**的黑曜石要塞，**断罪军团**铁血督战。
- **新增候选区域（可选）**：**翡翠林冠**（古精灵闭锁林海与妖精界交界）、**灰烬荒原诸部**（内陆游牧战歌草原）。
- **四大边陲绝险走廊**：**玻璃之漠巡逻走廊**（古禁咒熔融玻璃死地）、**时滞石林**（流速错乱且不可回溯的灰石柱林）、**哭泣巨松林**（妖精节点幻听密林）、**溺亡内海群礁**（旧帝国沉舰无风暗礁）。

## 四、种族、五道法统、九神与演化八线
- **九族与三大远古血脉**：人类、精灵、矮人、半身人、兽人、龙裔、侏儒（原称：地精；专指工匠精算族，荒野 Goblin 怪物方称地精）、妖精族、魔族（`提夫林`），及**神启天界裔**（`阿斯莫`）、**渊喉深渊魔裔**（`提夫林`）、**巨石霜裔**（`歌利亚`）。法定成年 **17 岁**。
- **五道法统与二元奥术**：**魔法**（八大学派模态构架 × 十七元素质料：九基元＋高阶八元）、**神术**、**巫术**（四灵）、**魂法**（三阶）、**隐道**（隐世之境），皆归入 D&D 2024 十二职业与武器精通结算。
- **万神殿九主神与四大地下结社**：锻炉**奥尔登**、银灯**薇尔拉**、穗冠**泰拉**、严霜**扎卡里**、安魂**缄默骨翁**、破浪**玛恩**、灰烬**索林**、晨曦**索拉里斯**、暗影**无眼之神**（及边地**野性与狩猎**）；跨国暗网为**生锈链条**、**白烛净涤社**、**织线者之环**、**深渊升降机行会**。
- **演化八线**：`战争 · 王位更替 · 教会分裂 · 学院新论 · 魔法技术 · 魔兽迁徙 · 魔族动向 · 商路兴衰`，随世界时钟独立推进。
