# 卷二 · 历史、时代与演化八线 (History, Eras & Evolution Tracks)

## 一、七纪元历史（大陆通行史观）

> *母本副题：七纪元历史（大陆通行史观，不等于全部真相）*

| 纪元 | 核心事件 | 当代遗存与历史回响 |
| :--- | :--- | :--- |
| **神启纪** | 诸神降临，与凡人立下圣约 | 神殿体系、圣约法统、神血后裔遗族、极北**永冬王座**远古冰碑 |
| **古族纪** | 精灵、矮人先民鼎盛，真龙盘踞云巅 | 巨型古代遗迹、失传秘银锻造、古树迷锁、绵延至今的种族世仇 |
| **辉法纪** | 魔法文明极度繁荣，因狂妄傲慢自毁 | 魔法荒原（**玻璃之漠**）、禁断秘术残卷、地下城与浮空城成因 |
| **列王纪** | 人类崛起，诸国格局最终奠定 | 现行国界、贵族血统谱系、古长城堡群与王朝正统 |
| **崩渊纪** | 第一次大魔灾爆发，深渊裂隙贯穿物质界 | 魔潮残区、畸变生物、**哀嚎裂谷**、教会因驱潮救世而登顶 |
| **帝国纪** | 帝国短暂实现全大陆统一后迅速分裂崩解 | 旧帝国龙纹金币仍为通用贸易基准硬通货、旧行省边界、通用官话 |
| **剑火纪** | 旧秩序崩解，新秩序尚未成形（当代主舞台） | 处处是机会，诸雄割据，侏儒魔导工学萌芽，暗流汹涌，余烬未熄 |

## 二、时代 × 世界状态对照（建局锚点）

> *母本副题：时代 × 世界状态对照（建局选时代的定调锚点）*

玩家默认以当代**剑火纪**入局；若开局选择回溯其他历史锚点，DM 按下表定调并结合本局生成具体势力。核心原则：**时代只改变世界的状态，不改变卷一至卷五的规则与代价体系。**（无论身处哪一时代，D&D 2024 数值规则、职业与豁免体系完全一致。）

| 时代 | 对应历史锚点 | 世界状态定调 | 主要戏剧张力 |
| :--- | :--- | :--- | :--- |
| **黄金王国时代** | 列王纪盛世 | 王权强盛，教会辅政，超凡力量受王室严格登记管束；冒险者公会初露锋芒 | 王位继承之争、旧贵族与新兴商会的权力换手 |
| **魔法繁荣时代** | 辉法纪中期 | 学院与法师塔鼎盛，魔法渗入生活日常（魔导灯具、魔导车辙）；浮空城高悬天空 | 魔法傲慢在积蓄，繁荣顶点即崩溃前夜（可暗埋辉法纪自毁远因） |
| **群雄割据时代** | 帝国纪崩溃后 | 帝国法统荡然无存，佣兵团、僭主领主与城邦联盟并立；帝国金币为唯一硬通货 | 谁能重聚法统；夹缝中小势力的残酷求生 |
| **第二次大魔灾前夕** | 剑火纪·暗流期 | 表面太平，但魔潮征兆渐密（畸变目击、渊喉怪响、巫者通灵躁动） | 知情高层的隐瞒备战 vs 无知平民的日常求生 |
| **魔族入侵时代** | 崩渊纪当代重演 | 魔界内战败者出走，大军压境物质界；三国临时同盟貌合神离、各怀鬼胎 | 前线铁血抵抗 vs 境内对魔族的清洗猜忌与同盟内部算计 |
| **战后重建时代** | 大战后的剑火纪 | 大战刚歇：废墟、瘟疫横行、孤儿流民遍地；魔晶因战争消耗殆尽而价格暴涨 | 重建与弱肉强食、旧账清算、“战争真的结束了吗” |

**说明**：时代烈度参数叠加在此定调之上；跨代续局时，时代可沿历史长河自然流动——黄金王国的子孙可能活到群雄割据。

## 三、世界奇观（GM 可增删）

每处奇观均有住民、政治与高昂代价，绝非单纯背景板；其深层成因留给主持 DM 与玩家探索定案（记入 `canon`）：

- **世界树残枝**：刺穿云霄的石化巨木，无人知晓树的本源是否依然存活。
- **沉没帝都**：半淹于西南内海与沉日绿沼交界处的古帝国旧都，水下溺亡者面容栩栩如生，传说保留着未启封的帝国国库。
- **玻璃之漠**：上古辉法纪禁咒对撞将整支大军连同广袤沙漠熔融为坚硬黑绿玻璃的死地。
- **逆瀑**：自地面径直倒流向天穹的魔力河流，直通某座神秘的未知浮空城。
- **永冬王座**：矗立在极北冰原深处的神启纪万年寒冰巨座——民间歌谣传唱王座上凝结着不散的古老霜影，自极寒降临的那一夜起，极北的暴风雪至今未停（王座上究竟是空寂古碑、自然寒核还是古纪元遗骸，属未定悬案）。
- **星坠之环**：天外异物撞击形成的环形山脉，环心陨铁每逢子夜发出低沉的共振歌声。
- **万门之城**：围绕上千座来历不明、通往不同未知地域与位面的古老石门建立的法外自由港（门后世界开放留白）。
- **哀嚎裂谷**：崩渊纪第一次大魔灾撕裂大地的永久创口，深处与深渊裂口相通，终年回荡着硫磺气流的哀鸣。
- **无风之海**：风力和声音彻底消失的绝望水域，驶入其中的船只皆陷入死寂。

## 四、演化八线（世界独立推进引擎）

**战争 · 王位更替 · 教会分裂 · 学院新论 · 魔法技术 · 魔兽迁徙 · 魔族动向 · 商路兴衰**——独立演算推进，不等玩家；跨阶段须有世界内事件与时钟支撑，不凭空跳档：

| 演化线 | 各线阶段刻度（GM 沿刻度推进，由 SCHEMA 世界时钟按当前阶段输出） |
| :--- | :--- |
| **战争** | 边境摩擦 → 全面动员 → 正式开战 → 胶着相持 → 终战（胜/和/溃败）→ 战后余波 |
| **王位更替** | 老王衰颓 → 继承纷争浮出水面 → 宫廷摊牌 → 大局已定 → 新王清洗异己 |
| **教会分裂** | 派系暗斗 → 教义争端公开化 → 决裂/立伪宗 → 成立武装圣军 或 妥协媾和 → 新格局 |
| **学院新论** | 私下密传 → 论文公开震撼学界 → 学派大论战 → 列为异端被禁 或 编入正统正典 |
| **魔法技术** | 理论雏形 → 密室试验验证 → 小范围定制应用 → 商业化普及 → 颠覆旧行业（招致反扑） |
| **魔兽迁徙** | 异变目击 → 局部兽灾爆发 → 跨区域大迁徙 → 建立新领地生态 或 被联合剿灭 |
| **魔族动向** | 零星斥候渗透 → 暗桩势力布局 → 挑起边境事端 → 与周边人类割据势力媾和或开战 |
| **商路兴衰** | 谣言风声 → 商队谨慎改道 → 建立新兴商路 → 贸易集市繁盛 → 被战火/劫匪扼杀（循环） |

### 当代演化实例素材（传说/可选，供建局抽取挂接八线）
- *挂接【魔兽迁徙 / 战争】*：北境冬线往年每年仅南移一寸，今年骤推半里，极地冰铠熊与冻原氏族被迫南压冲击拒冬墙。
- *挂接【魔法技术 / 商路兴衰】*：万门海湾与内陆商盟的`侏儒` (#544) 魔导工坊将魔晶动力引入航运与矿山，冲击传统铁匠公会与飞天索道垄断。
- *挂接【教会分裂】*：圣座同盟借驱潮与反死灵之名东派审讯骑兵，与地方领主及灰烬学者教派摩擦日盛。

## 五、灾厄原则与传说形成律（母本救回定案）

- **灾厄原则**：杀死顶端头目，威胁仍会改换形态继续存在（直到深层矛盾被疏导）；灾厄按自身周期行动，玩家往往先遇余波后见源头；劫级沉眠在“门后”，不主动机械登场；世间传奇人物立场独立，可与玩家并肩作战或交易，但不可收编为私人随从。
- **传说形成律**：一切史迹经民间口传、教会神学删改、学院偏见注疏与史官春秋笔法层层加工——后世读到的记录永远真伪参半。唯有玩家亲临遗迹查证，本局真相方才落入存档 `canon`。
