# 卷一 · 世界基本规则与地理框架 (World Rules & Geography)

> 旧帝国的剑已折断，新秩序的火尚未点燃——这是一个所有道路都还没被封死的时代。

## 使用说明（GM 必读）

- **世界事实来源**与**优先级**（承接母本《剑火纪元》世界设定集（Skill 配套参考）卷一与卷二 · 地理与历史）：在剑火纪元沙盒（D 模式）中，**D&D 2024 数值、动作、施法与休息规则为最高准绳**；其次为本存档已定案的既定事实（`canon`）；再次为 `worlds/jianhuo/lore/*.md` 设定切片。**加载时机**与**卷章对应**按 `capsule.md` 路由按需微创调阅，不单回合全量灌入。
- **命名规则**与**拓展原则**：本设定集只给开放骨架与高质感种子，未覆盖细节由 DM 按世界逻辑现场生成；**除各条目的“骨架”与 2024 规则硬边界外，DM 可自由改写“素材（传说/可选）”，改动一经桌边成立即记入存档 `canon`，此后前后一致**。
- **文风**：克制、具体、明码标价；少空泛形容词，多写物理质感与现实后果。
- **谱系定位（风格总锚，约束一切描写与命名）**：本世界属于**西方奇幻传统**（《龙与地下城》《指环王》《魔兽世界》一脉）——位面宇宙与多种族共存是它的骨架，魔法作为被社会管理的力量是它的日常，旧秩序崩解的余烬史诗感是它的基调：精灵的长寿与疏离、矮人的石厅与锻炉、兽人的部族与战歌、侏儒的魔导工学、魔族的契约与阶序。视觉与质感的想象基准：王座厅、纹章、挂毯、石砌城堡、公会、法师塔、神殿、集市、酒馆、佣兵——而非任何东方式宫廷、庙堂或武侠意象。**这个世界不是对上述任何作品的模仿，它有自己的具体质感（浮空城的粮食软肋、侏儒的魔导工学、五道法统的社会位置），一切描写从设定集推导，而非从作品记忆里搬。**
- **机密防泄露底线**：凡归入 `secret/gm-dossier.md`（标为【GM 内档】）的候选真相，**泄露即事故**——绝不直接出现在给玩家的旁白或公开视图中，唯经调查行动逐步揭开。
- **母本保密原句（原称）**：“**标注为【GM 内档】的内容，绝不出现在给玩家的叙事、选项、状态面板中**”——D 模式下“状态面板”对应 `world status` / `world rumor` 等公开视图，原则不变。

## 一、世界七律

| 律 | 内容 | 执行原则（对齐 D&D 2024 与沙盒引擎） |
| :--- | :--- | :--- |
| **恒动** | 世界在玩家不在场时也持续变化 | 势力推进计划，时钟与演化八线不因玩家离场而暂停。 |
| **稀缺** | 一切资源有成本；重复做低难度的事，收益递减 | 拒绝刷怪刷钱式无脑积累，高阶施法者、足赤龙纹金币与极品魔晶皆稀缺。 |
| **代价** | 魔法、神术、机缘、政治全部明码标价 | 玩家没有默认的传奇血统或开局神器，契约、庇护与越级担保皆记入 `ledger`。 |
| **凡识** | 开局认知受身份限定；高层知识必须付出代价 | 严禁上帝视角，按地点五层认知门槛过滤传闻，允许民间流言失真。 |
| **因果** | 因果链长期有效；改革必损既得利益者，并招来反扑 | 任何重大杀伐、赖账或变革必招致反弹，余波持续追讨。 |
| **死亡** | 死亡是真实的；NPC 不因玩家喜欢而复活 | 重要 NPC 死亡即归入逝者档案；D&D 2024 复活法术机制有效但伴随沉重社会余波。 |
| **惯性** | 旧战争、旧法统、旧仇恨持续塑造当下 | 百年宿怨与教派壁垒压在每个角色肩头，声望与立场逐档推移。 |

### 节制

世界级大事件极少发生，且未必与玩家有关。绝大多数日子里，压在凡人肩上的是断粮的边堡、掺铅的银币与未结的血债。

## 二、硬约束（不可违反）

> *D&D 2024 兼容校准说明*：

1. **法术不可无限叠加**：同名或同类效应的叠加严格遵循 D&D 2024 专注与效应合并规则；鲁莽乱叠高危法阵在叙事上亦可能诱发工坊事故。
2. **治疗不可无限复活（2024 复活规则对齐）**：
   - **机制准绳**：D&D 2024 规则库中的一切合法复活法术（如三环回生术、五环死者复活、七环复生术等），只要施法者具备对应环阶法术位并备妥法术规定的钻石耗材，**在机制上始终有效，绝不触发任何法外自动抹杀、失败检定或永久属性扣减**。
   - **世界稀缺与宗教追责**：所谓“不可无限复活”，指在剑火纪元能施展五环以上神术的大主教与高价值纯净钻石凤毛麟角；且亡者复生在世俗与神学上被视作触犯生死界限的敏感大事——公开令显贵或关键证人死而复生，极易招致奉行“死者入土”的**缄默骨翁**教会、遗产继承人或政敌的现实追索。
3. **时间不可无限回溯**：时间没有倒车，一切选择产生不可逆的涟漪。
4. **空间魔法不可无限复制资源**：物质守恒，虚空不能凭空刷取永恒财富。

## 三、魔潮（崩渊纪的遗产）

**魔潮是深渊魔力沿裂隙向物质界的周期性渗透**——如潮汐，涨落无常。
- **上涌时**：裂隙周边的生灵与土地被浸染（畸变体、魔潮残区皆由此而来），环境异象频发，动物先行逃离。
- **由弱到强的物理征兆**：`井水发苦 → 铁器夜鸣 → 动物迁徙 → 畸花绽放 → 天空变色`。
- **退去后**：留下魔潮残区，土地百年生机断绝、不宜居住。教会至今保有崩渊纪驱潮的仪式残卷——这是其统治合法性与政治资本的核心来源之一。

## 四、五层认知门槛（决定开局知晓边界）

> *对应母本：五层认知门槛（决定开局知道什么）*
> - **历法**：一年十二个月（`1 年 = 4 季 = 12 月 = 360 天`，每月上、中、下旬各 `10 天`），以纪元代年（默认当代为**剑火纪**，开局年份由 DM 设定）；每日分 `深夜 / 黎明（04:00 时钟结算边界）/ 上午 / 下午 / 黄昏 / 夜` 六时段。

| 层级 | 涵盖范围 | 开局认知原则 |
| :--- | :--- | :--- |
| **凡俗层** | 村庄、城镇、商路、港口 | 人尽皆知，常识范畴。 |
| **文明层** | 王国、教会、学院、商会 | 人尽皆知，了解表面架构与公开政令。 |
| **超凡层** | 法师塔、神殿秘辛、公会高阶、地下城 | 至少听说过，知晓风险与真伪参半的流言。 |
| **异界层** | 精灵领域、矮人深王宫、龙巢、深渊、浮空城 | 知其名，不知其里，凡人极难触碰。 |
| **诸界层** | 物质界、神国、虚空、原初之海、梦境 | 极少数涉密者与传奇阶层方能接触（注：**隐世之境**独立于公共五层表之外）。 |

*注：五层管“知道什么”，垂直三界管“人在哪里”，两套体系独立。稳定进出高层级地点必有代价，绝无廉价往返。*

## 五、垂直三界

- **苍穹层**：
  - 浮空城三种下场：
    1. **坠落者**：陨城遗址，是地面上最凶险的古代地下城；
    2. **沉眠者**：云端漂行的“暗城”，与世隔绝；
    3. **存续者**：垄断古代技艺，但粮食依赖地面供应——永远的致命软肋。
  - **认知例外**：设有天港且与地面保持稳定粮食贸易的存续者浮空城（如埃瑟加德），对常来贸易者与天港居民视同超凡层认知（知其运作，不知其核心技艺内幕）；其余浮空城一律属异界层。
- **地表层**：凡人世界主舞台。
  - 五种魔法地貌：**禁魔区、魔泉区、元素异变区、时滞带、龙脉交汇处**——地貌本身就是历史遗迹。
  - **时滞带边界**：时滞带内时间流速快慢不均，但**不可回溯**（**绝对不可回溯**）——走出时滞带的人没有变年轻的，只有衰老或几乎维持原状者，绝不触碰“时间不可无限回溯”的硬约束。
- **地底层**：
  - **浅窟**：矿道、矮人前哨城、地下走私商路；
  - **地底世界**：无日世界，拥有独立种族与城邦文明，相当于另一片大陆；
  - **渊喉**：通往深渊裂口，越深入时间与空间异变越剧烈（最深处向 DM 开放留白，不写死尽头）。

## 六、威胁四阶标尺（患 · 难 · 灾 · 劫）

- **患**（一郡 / 领地，建议对应 0–4 级）：强盗肆虐、矿坑盲蝠筑巢、局部饥荒或邪祀潜伏；凡人小队可凭智勇平息。
- **难**（一国 / 大教区，建议对应 5–10 级）：边境开战、领主叛乱、泥沼疫潮外溢；常需借重大型公会、地方军团或釜底抽薪之策周旋。
- **灾**（一洲 / 大陆级，建议对应 11–16 级）：魔潮大规模上涌、跨国圣战清洗、冬线大幅南压。
- **劫**（一纪，跨纪元文明重新洗牌，建议对应 17–20+ 级）：沉眠在“门后”的终极危机，不主动机械降临。每一活跃威胁皆须具备源头、时钟与至少两条化解路径（含非死斗路径）。
