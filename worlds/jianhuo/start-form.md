## 二、DM 建档与初始化执行指令（确认表单后立即运行）

当玩家回复表单（或说“按默认/随机来一局剑火沙盒”）后，DM 依次执行以下两条终端命令完成双状态机建档：

### 1. 初始化角色状态（`state.json`，统一铜币 `inventory.copper`）
- **若为 0 级凡人序章**：
  ```bash
  node <SKILL_DIR>/scripts/state.js init <campaign> --mode D --level 0 --name "<角色名>" --species "<族裔>" --class "平民" --copper <初始铜币如150> --location "<开局地点>"
  ```
- **若为 1 级正式冒险者**：
  ```bash
  node <SKILL_DIR>/scripts/state.js init <campaign> --mode D --level 1 --name "<角色名>" --species "<族裔>" --class "<2024职业>" --hp <最大HP> --ac <AC> --copper <初始铜币如1500> --location "<开局地点>"
  ```

### 2. 初始化剑火世界状态（`world.json`，不写死地点、生成 3 患 + 转化 ★/◆ + 启动 3–4 条演化线）
```bash
node <SKILL_DIR>/scripts/world.js init <campaign> \
  --seed <随机种子如20261107> \
  --danger <forgiving|standard|gritty> \
  --intensity <slow|standard|fast> \
  --magic-level <low|standard|high> \
  --style <grounded|heroic|dark> \
  --region "<开局大区名>" \
  --location "<开局具体地点名>" \
  --tier <凡俗|文明|超凡> \
  --factions "<势力1>,<势力2>" \
  --cost "<★代价描述>" \
  --limit "<◆限制描述>"
```

### 3. 开局第一幕呈现规范
1. 运行 `node <SKILL_DIR>/scripts/world.js status <campaign>` 核对已生成的 **3 个“患”级局部问题**（`clk:trouble_1..3` 与 `led:trouble_1..3`）、**★代价 / ◆限制** 账本，以及当前启动的 **3–4 条区域演化线**。
2. 若开局涉及特定国度或组织细节，按需调用一次 `node <SKILL_DIR>/scripts/lookup.js lore "<开局国度或组织名>" --brief` 获取风物切片。
3. 在首幕正文中，用冷峻扎实的西方奇幻笔触描绘开局聚落的光影、气味、物价（以 `gp/sp/cp` 计）与眼前的第一桩近忧，并在末尾打印 `state.js` 单行 HUD，把行动权交给玩家。
